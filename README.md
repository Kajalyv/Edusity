# 🎓 Edusity - Educational Platform Website

Edusity is a modern and responsive educational website built using React.js. The project is designed to provide an engaging user experience for students and visitors by showcasing educational programs, campus information, testimonials, and contact details through a clean and interactive interface.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/edusity.git
```

### Navigate to the Project Directory

```bash
cd edusity
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm start
```

The application will run locally on:

```text
http://localhost:3000
```
